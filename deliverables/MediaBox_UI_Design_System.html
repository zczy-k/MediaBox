MediaBox · UI Design Spec

流光 Lumen
一套克制的影视界面语言

以「内容先行、控件退后」为原则重构 MediaBox 的界面层。保留现有的 Compose + Material 3 技术底座与四页签信息架构，把视觉噪音压到最低，让海报和标题成为唯一的视觉主角。

版本 v1.0 2026-10-19 基线：Compose Material 3 + MaterialKolor 主色 #0F766E 明暗双模
01

设计判断：先修三处硬伤

基于现有代码实测
问题 01 · 主色分裂
两套主色同时存在
ThemeConfig.kt 的种子色是 #0F766E（青绿），而 colors.xml 里 colorPrimary 仍是 #2563EB（蓝）。启动首帧、系统栏、XML 主题与 Compose 主题不同源，冷启动会闪一下蓝。
问题 02 · 视觉权重
控件比内容更抢眼
顶栏、悬浮导航、卡片描边、圆角各自为政，缺少统一的层级规则；一屏里同时存在 3 种圆角和 4 种阴影强度，海报反而被压成背景。
问题 03 · 状态缺失
等待与失败不可读
跨站搜索是并发聚合，18 个源同时返回，但界面只给一个转圈。用户无法知道「还差几个源」「哪个源挂了」，失败与空结果在视觉上无法区分。
本方案的三条铁律：① 一个主色，一条色阶，不做渐变花活；② 内容层级只靠「尺寸 + 留白 + 字重」，不靠边框和阴影堆叠；③ 任何异步状态都必须有可读的进度与终态，不允许无限转圈。
02

视觉语言：色彩 · 字体 · 尺度

Design Tokens

2.1 色彩系统

以 #0F766E 为唯一品牌色，围绕它生成 5 级青绿阶 + 6 级中性阶。中性色带极轻的青绿倾向（不是纯灰），让整屏有统一的冷感而不发脏。

落地动作：把 colors.xml 的 colorPrimary / colorPrimaryDark / colorAccent 改成 #0F766E / #0B5A54 / #7DE3D4，与 MediaBoxSeedArgb 同源。这一步不改任何布局，只消除冷启动色闪。

2.2 字体阶梯

只保留 6 级。中文用系统字重 500/600 承担层级，不用 300 细体（小屏发虚），也不用 700 以上（挤压字腔）。

2.3 尺度与圆角

间距网格4pt 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。页面左右安全边距统一 16dp，区块之间 24dp，同区块内元素 8–12dp。
圆角只有三档：小件 10dp（缩略图、集数格）、卡片 16dp、容器 22–28dp（Hero、底部弹层）、胶囊 999dp（按钮、搜索框、导航）。禁止再出现其它圆角值。
阴影三级，且只有浮层才允许用阴影：sh-1 卡片静止态、sh-2 卡片按下/悬浮、sh-3 弹层与悬浮导航。列表内的卡片一律用 1px 描边代替阴影，避免滚动时脏边。
触摸目标最小 48×48dp，图标视觉尺寸 20–24dp，但热区必须撑满 48dp。返回、收藏、更多这类角标按钮用 44dp 圆形热区 + 视觉 28dp。
海报比例列表统一 2:3；横滑「继续观看」用 16:9 裁切；详情页头图 16:9 → 21:9 渐隐。同一屏内不得混用两种以上比例。

04

关键组件规格

可直接落到 Compose
悬浮导航 FloatingNavBar高 52dp，左右 16dp，距底 12dp，胶囊全圆角。玻璃层：白色 82% + blur 18 + saturate 1.6，1px 高光描边。选中项用 Brand Soft 底色 + Brand 图标 + 字重 700，不做位移放大（位移会在玻璃层里产生脏影）。页面滚动时允许 透明度 1 → 0.72 过渡，但不隐藏。
海报卡 VodCard比例 2:3，圆角 10dp，无描边。角标分两类：左上放「新 / 独播」（Brand 底白字，9sp），右下放集数（黑色 50% 底白字）。标题在卡下 10.5sp / 1 行省略，不用两行——两行会让网格高度抖动。按下态：scale 0.97 + sh-2，120ms。
Hero 轮播 HeroCarousel高 158dp（约 16:9.5），圆角 22dp。文字压在下三分之一，配 底部 78dp 黑色 72% 渐变保证任何海报上都可读。轮播 5s 自动切换，手指按下即暂停、松手续走。指示点用「短条 + 圆点」：当前项 13×4，其余 4×4。
搜索框 SearchField高 38dp，胶囊。聚焦态：1.5dp Brand 描边 + 外发光 3dp（Brand 10%），光标为 1.5dp 竖条。清空按钮只在有输入时出现，热区 48dp。不做「搜索按钮」——输入即搜（300ms 防抖），这是移动端预期。
源状态条搜索页顶部固定一条 3dp 进度线 + 一行计数：已返回 12/18 · 失败 2 · 超时 1。进度线用 Brand，失败数用 Danger，超时用 Accent。全部终态后进度线 2s 内淡出，计数行保留（用户需要知道有源没搜到）。
骨架屏 Skeleton结构与真实内容完全同尺寸（海报 2:3、标题 1 行），底色 Surface-2，用 1.2s 呼吸（透明度 1 ↔ 0.55）而非左右扫光——扫光在暗色海报旁显得廉价。加载超过 600ms 才显示，避免闪烁。
空态 / 失败态三件套：24dp 线性图标 + 一句人话 + 一个明确动作。例：「这个源没搜到 · 换个关键词 / 只搜这个源」。禁止只显示「暂无数据」——那等于把问题丢给用户。
底部弹层 BottomSheet顶部圆角 28dp，把手 32×4dp、Surface-2 色、上边距 10dp。遮罩 黑 40%，点击可关。内部左右边距 20dp，底部留 导航栏高度 + 16dp。
05

动效：只做三件事

Motion
场景动作时长 / 曲线目的
页面切换新页从右滑入 24dp + 淡入，旧页左移 12dp + 降到 0.96320ms · emphasized建立前后关系，不炫技
卡片按下scale 1 → 0.97，阴影 sh-1 → sh-2120ms · standard即时触觉反馈
详情页展开海报从列表位置放大为头图（共享元素）380ms · emphasized让「我点的就是它」成立
搜索结果新条目从顶部插入，高度 0 → auto + 淡入220ms · decelerate体现流式到达
播放器控制层淡入 150ms / 3s 无操作淡出150ms · linear不遮挡画面
不做：弹性回弹、粒子、渐变流动、图标旋转。这类效果在影视类 App 里只会稀释内容的注意力，且低端机掉帧明显。
06

可用性检查清单

验收标准
导航与可达性
☑ 四个一级页签常驻，任何页面 ≤ 2 次点击回到首页
☑ 搜索入口在首页顶部固定，滚动时不隐藏
☑ 返回手势与返回按钮行为一致（不出现「返回两次才退出」）
☑ 详情页返回保留列表滚动位置
反馈与状态
☑ 所有异步操作在 100ms 内有可见反馈
☑ 跨站搜索显示「已返回/总数」，并区分失败与超时
☑ 加载超过 600ms 才出骨架，避免闪烁
☑ 失败态提供重试入口，而不是死路
可读性
☑ 正文对比度 ≥ 4.5:1，次要文字 ≥ 4.5:1（不用 #9DADA9 做正文）
☑ 最小可点区域 48×48dp
☑ 长标题单行省略，不换行撑高卡片
☑ 深色模式下海报边框改为 1px 白 8%，避免融进背景
一致性
☑ 全 App 只有 1 个主色、3 档圆角、3 级阴影
☑ 间距只用 4 的倍数
☑ 图标统一线性 2dp 描边、24dp 画布
☑ 数字与时间统一等宽字体，避免进度条跳动
