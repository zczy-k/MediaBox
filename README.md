# MediaBox

一个用 Jetpack Compose 写的空壳媒体播放器（Android）。

## 功能

- 多源聚合：支持 TVBox / 自建源配置，首页栅格、分类筛选、搜索
- 播放器：多内核切换、倍速、画面比例、片头片尾
- 字幕：内置 + 本地 + 在线搜索（Assrt / SubtitleCat / 迅雷），支持自定义字幕源、字号、描边样式、精确延时
- 画质增强：画质预设、自定义调色、Anime4K 超分
- 弹幕、投屏、音乐播放页、历史与收藏
